Song API

Jo songs app me online dikhte hain unka source yahan se control hota hai. Save karte hi app me turant lagu ho jata hai.

Full song API — link paste karo

Apni download API ka poora link yahan paste karo. Song ka naam / url= wala hissa aur api_key= apne-aap alag ho jata hai. Ye ON hone par songs full audio me chalenge (preview ki jagah).

Kaise kaam karta hai

iTunes: koi key nahi chahiye. Sirf 30 second ka preview milta hai.

Jamendo: developer.jamendo.com par free account banao, "Client ID" copy karke upar key me daalo. Full songs milte hain.

Custom: apni API ka URL daalo. URL me {query}, {limit}, {offset}, {page} aur {key} likh sakte ho. Key "Key header" me bhi ja sakti hai (jaise Authorization).

Response JSON me har song ke liye title aur audio link (url / preview / audio / src) hona chahiye.

Dhyan rakho: ye app sirf front-end hai, isliye key browser me save hoti hai. Kisi aur ko dikhane layak secret key yahan na daalo.
